# 🎓 Exam Seat Allotment System

An Exam Seat Allotment System designed to simplify the process of allocating examination seats to students. The project aims to organize student seating efficiently, reduce manual work, and help prevent confusion during examinations.

## 📌 Project Overview

Managing examination seating manually can be time-consuming and prone to errors. This project provides a software-based approach to managing examination seating arrangements in a more organized and efficient manner.

The application is divided into a frontend and a backend to separate the user interface from the application logic.

## ✨ Features

- **Seat Allotment:** Organizes the examination seat allocation process.
- **Student Management:** Supports managing student-related information, depending on the implemented functionality.
- **Organized Seating:** Helps maintain structured examination seating arrangements.
- **Frontend Interface:** Provides a user interface for interacting with the application.
- **Backend Processing:** Handles application logic and data processing.
- **Modular Architecture:** Separates frontend and backend components for easier maintenance.

## 🛠️ Technologies Used

- **Frontend:** Technologies used in `exam-seat-frontend`

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/sivapriyakoppakaa/exam-seat-allotment-system.git
cd exam-seat-allotment-system
```

### 2. Set up the backend

```bash
cd exam-seat-backend
npm install
```

Start the backend using the command defined in its `package.json` file. For example, if a `start` script exists:

```bash
npm start
```

### 3. Set up the frontend

Open a new terminal and run:

```bash
cd exam-seat-allotment-system/exam-seat-frontend
npm install
```

Start the frontend using the command defined in its `package.json` file. For example, if a `start` script exists:

```bash
npm start
```

**Important:** The actual startup commands may differ depending on the scripts configured in each folder's `package.json`. The frontend may use `npm run dev` instead of `npm start`.

## 💻 Usage

1. Start the backend server.
2. Start the frontend application.
3. Open the local URL displayed in the terminal.
4. Use the available application features to manage examination seating.
5. Verify the seat allocation results through the application's interface.

The exact workflow depends on the features implemented in the current version.
